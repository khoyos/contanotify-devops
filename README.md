# DevOps - CI/CD Configuration

Este repositorio contiene la configuración necesaria para manejar el proceso de **CI/CD** del proyecto utilizando **Docker y Docker Compose**.

## 📦 Propósito

Centralizar toda la configuración relacionada con:

- Construcción de contenedores Docker
- Orquestación de servicios con `docker-compose`
- Automatización de despliegues
- Integración continua (CI)
- Despliegue continuo (CD)

Este repositorio **no contiene código fuente de las aplicaciones**, solo archivos de infraestructura y automatización.

## 📁 Estructura del Proyecto

### Descripción

- **docker-compose.yml**  
  Define los servicios necesarios para ejecutar el sistema (backend, frontend, base de datos, etc).

- **.env**  
  Variables de entorno utilizadas por Docker Compose.

- **scripts/**  
  Scripts utilizados para automatizar tareas de despliegue o construcción.
